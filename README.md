# Nagrik Setu

Nagrik Setu is a React/Vite prototype for citizen service discovery. It helps users browse public schemes, answer a guided eligibility flow, track mock applications, manage document readiness, and file grievances from one interface.

## Features

- Scheme discovery with profile-based matching
- Searchable scheme catalogue with filters and detail pages
- Mock citizen dashboard for saved schemes, applications, documents, and recommendations
- Grievance filing and grievance detail flows
- English/Hindi language switcher
- Accessibility toolbar for text size and high contrast
- Mock assistant for common scheme, application, and grievance questions

## Getting Started

```bash
npm install
npm run dev
```

## Useful Commands

```bash
npm run build
npm run lint
npm test
```
